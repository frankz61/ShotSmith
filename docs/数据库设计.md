# ShotSmith —— 数据库设计

> MySQL 8（InnoDB, utf8mb4）· 核心两张表：`task`（生成任务）1 — N `asset`（生成素材）
> 表由 SQLAlchemy 模型生成（`Base.metadata.create_all`），本文为等价 DDL 参考。

```sql
-- 生成任务
CREATE TABLE task (
    id            CHAR(32)    NOT NULL PRIMARY KEY,            -- 应用层生成 UUID(hex,无连字符)
    status        VARCHAR(16) NOT NULL DEFAULT 'pending',     -- pending/processing/success/partial/failed
    current_stage VARCHAR(16) NULL,                           -- ingest/matting/generate/postprocess/qc/package
    progress      SMALLINT    NOT NULL DEFAULT 0,             -- 0~100
    source_type   VARCHAR(8)  NOT NULL,                       -- upload / url
    source_ref    TEXT        NOT NULL,                       -- 上传文件名或图片 URL
    description   TEXT        NULL,                           -- 可选文字描述
    options       JSON        NOT NULL,                       -- image_types/sizes/style/candidates
    error_message TEXT        NULL,
    created_at    DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at    DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_task_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 生成素材
CREATE TABLE asset (
    id             CHAR(32)     NOT NULL PRIMARY KEY,
    task_id        CHAR(32)     NOT NULL,
    type           VARCHAR(16)  NOT NULL,                     -- cutout / white_bg / scene
    size_label     VARCHAR(16)  NULL,                         -- 1:1 / 3:4 / 4:5
    path           TEXT         NOT NULL,
    fidelity_score DECIMAL(4,3) NULL,                         -- 还原度 0~1，低于阈值转人工复核
    qc_status      VARCHAR(16)  NOT NULL DEFAULT 'pending',   -- pending/passed/needs_review/rejected
    selected       TINYINT(1)   NOT NULL DEFAULT 0,           -- 用户是否选用
    gen_params     JSON         NOT NULL,                     -- provider/prompt/seed
    created_at     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_asset_task_id (task_id),
    CONSTRAINT fk_asset_task FOREIGN KEY (task_id) REFERENCES task(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> 说明：`id` 用 `CHAR(32)`（SQLAlchemy `Uuid` 在 MySQL 上存 32 位 hex）；`JSON` 列不设 SQL 默认值，由应用层写入。二期再加 `batch_job`（批量）、`platform_spec`（平台尺寸规则）两张表。
